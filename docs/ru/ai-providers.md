# Провайдеры моделей и блоки автоматизаций у программ

Протокол — [spec/protocol.md](../../spec/protocol.md) §8.1 и §12. Подробнее по-английски —
[AI и автоматизации](../en/ai-and-automation.md).

## Провайдер модели (`contributes.ai`)

Расширение-программа может быть провайдером модели. В Настройки → AI появляется профиль из него (меню «+» →
«Из расширений»): название и иконка вклада, поля `fields` (секретные — в Keychain этого Mac, как ключи API
встроенных провайдеров; нужно право `secrets`), модели, которые перечислит программа, уровни `reasoning`. Профиль
выбирается везде, где выбираются профили: AI-панель, «Составить запрос», AI-фильтры, автоматизации.

Программа отвечает на три метода:

- `ai/models` — список моделей `[{id, title}]`;
- `ai/chat` — ответ: кусочки уведомлениями `ai/delta` (`text`, `tool_use`, `tool_input`, `progress`, `usage`) с id
  потока, в конце результат `{stop, usage, model, message?}`;
- `ai/cancel` — пользователь нажал «Стоп»: `ctx.signal` прерывается.

```ts
defineModule({
  handlers: {},
  ai: {
    models: () => [{ id: "echo-1", title: "Echo 1" }],
    async chat(req, ctx) {
      ctx.delta({ type: "text", text: "Привет" });
      return { stop: "end_turn" };
    },
  },
});
```

Программа получает то же, что встроенные провайдеры: запрос после маскировки секретов и политики режима AI. Вызов
инструмента, который «попросила» модель, проходит правила режима и подтверждения пользователя — сама программа
инструменты не выполняет. Пример без сети и настоящих моделей — `examples/ai-echo-provider`: печатает ответ
по словам, на «проверь сервер» вызывает `list_sessions`, затем `run_command uptime`.

## Блоки автоматизаций у программ

Блок модуля-программы вызывает свой обработчик в программе на этом Mac (`handler/call`): `input` — параметры
карточки, ответ — итог блока, как `$SK_RESULT` серверного блока (`{status, summary, value, items}` при
`returns: json`, строка — при `text` / `number` / `list`). Ошибка обработчика — ошибка шага с её текстом.

- `server: true` — у блока вход «сервер» (нужно право `exec`): `ctx.host.exec` идёт через сессии автоматизации —
  тот же профиль сервера, очередь входов, «без человека»: 2FA ночью — шаг ждёт человека.
- В окне разрешения — «программа расширения» на этом Mac, обработчик, параметры и риск из манифеста.
- «Стоп» запуска прерывает вызов (`ctx.signal`).
- «На сервере по cron» такой блок не выполнить: программа на этом Mac — установка на сервер отказывает с
  названием блока.

Пример — блоки `check_urls` (с сервера) и `check_urls_mac` (с этого Mac) в `examples/http-checks`.
