# Публикация

## Упаковка

```sh
sshkipper-ext pack            # проверяет, затем → <id>-<version>.sshkmod (у расширения — .sshkext)
sshkipper-ext pack -o dist/queues.sshkmod
```

`.sshkmod` — ZIP папки модуля с манифестом в корне (`.sshkext` — то же для расширения с `sshkipper-extension.json`):
ровно те файлы, которые хеширует приложение (всё, кроме папок `.git` и `.DS_Store`). Пределы: 2 000 файлов, 64 МБ.

## Установка

Настройки → Расширения → **«Установить расширение…»** берёт папку, `.sshkext` или `.sshkmod`. Перед установкой
приложение показывает, что просит модуль: права, что выполняется на серверах, его инструменты AI и блоки
автоматизаций. Оно копирует модуль в свою папку и запоминает SHA-256 каждого файла.

- Изменился файл установленного модуля — модуль выключается, пока пользователь не разрешит его снова
  («Разрешить как есть…»).
- **«Папка разработки…»** подключает папку вместо копии: приложение перечитывает её при каждом изменении файлов и
  помечает «из папки». Пользуйтесь ею, пока пишете.
- В том же списке модуль можно выключить, удалить или открыть его журнал (меню «⋯» → «Журнал…»).

## Версии

- `version` — семантическая. Новая версия, установленная поверх старой, сохраняет настройки пользователей (они
  хранятся по `id` модуля и `key` настройки): переименовывайте настройку только в мажорной версии и какое-то время
  читайте старый ключ.
- `sdk` — мажорная версия протокола. Новая мажорная версия протокола получит новый номер; приложение продолжит
  выполнять модули тех версий, которые знает.

## Каталог

Запланирован открытый каталог модулей (репозиторий GitHub со списком релизов `.sshkmod` и их хешами); пока делитесь
файлом или ссылкой на релиз.

## Прежде чем делиться

- `sshkipper-ext validate` проходит чисто (предупреждения объяснены в вашем README).
- У текстовых параметров, которые доходят до скриптов, есть `pattern`.
- У каждого действия `change`/`danger` есть вопрос `confirm`, который называет, что оно меняет.
- Описания инструментов говорят, что они возвращают.
- README говорит, что модулю нужно на сервере (`redis-cli`, `systemctl`…) и что он меняет.
