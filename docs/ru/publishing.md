# Публикация

## Упаковка

```sh
sshkipper-ext pack            # проверяет, затем → <id>-<version>.sshkext (у sshkipper-module.json — .sshkmod)
sshkipper-ext pack -o dist/queues.sshkext
```

Пакет — ZIP папки с манифестом в корне: `.sshkext` у расширения (`sshkipper-extension.json`), `.sshkmod` у модуля
(`sshkipper-module.json`) — ровно те файлы, которые хеширует приложение (всё, кроме папок `.git` и `.DS_Store`).
Пределы: 2 000 файлов, 64 МБ; без символических ссылок и путей за пределы папки. Программа на компилируемом языке
(Swift, Go, Rust) едет готовым файлом: собирайте её вне папки, чтобы в пакет не попала папка сборки ([Swift](swift.md)).

## Установка

Настройки → Расширения → **«Установить расширение…»** берёт папку, `.sshkext` или `.sshkmod` (двойной щелчок по файлу
в Finder — то же). Перед установкой приложение показывает, что расширение добавляет (его вклады), где выполняется его
код, права словами, инструменты AI и блоки автоматизаций и что автор не проверен. Оно копирует пакет в свою папку и
запоминает SHA-256 каждого файла.

- Файлы программы сверяются заново **перед каждым запуском**: изменённый, добавленный или удалённый файл не даёт ей
  запуститься, расширение помечается изменённым, пока пользователь не разрешит его снова («Разрешить как есть…»).
- **«Папка разработки…»** подключает папку вместо копии: приложение перечитывает её при каждом изменении файлов и
  помечает «из папки». Пользуйтесь ею, пока пишете.
- Меню «⋯» расширения в списке: «Журнал…» (что каждый обработчик написал в stderr, сколько шёл, что упало), Finder,
  удаление.

## Версии

- `version` — семантическая. Новая версия, установленная поверх старой, сохраняет настройки пользователей (они
  хранятся по `id` и `key` настройки): переименовывайте настройку только в мажорной версии и какое-то время читайте
  старый ключ.
- Обновление, которое добавляет право или вклад, ставится **выключенным**, пока пользователь его не включит.
- `sdk` — мажорная версия протокола. Новая мажорная версия протокола получит новый номер; приложение продолжит
  выполнять расширения тех версий, которые знает, а более новые отклонит с «обновите SSHKipper».

## Библиотека

Библиотека SSHKipper — расширения, которые мы проверили («Проверено SSHKipper»), — это подписанный список: автор
присылает pull request с исходниками, мы читаем код, CI собирает пакет, владелец подписывает список (бинарников от
автора не принимаем). Установленное расширение показывается «Проверено SSHKipper», пока его id, версия и файлы
совпадают с записью списка. Библиотека пока не опубликована; до тех пор делитесь файлом пакета или ссылкой на релиз.

## Прежде чем делиться

- `sshkipper-ext validate` проходит чисто (предупреждения объяснены в вашем README).
- У текстовых параметров, которые доходят до скриптов, есть `pattern`.
- У каждого действия `change`/`danger` есть вопрос `confirm`, который называет, что оно меняет.
- Описания инструментов говорят, что они возвращают.
- README говорит, что расширению нужно (на сервере — `redis-cli`, `systemctl`…; на этом Mac — Node 24 для программы на
  TypeScript) и что оно меняет.
