# Импорт и консоли

Два вклада расширения, которые работают программой на этом Mac (`runtime.kind: "process"`): **импорт** превращает
файл другой программы в папки и подключения, **консоль** передаёт текстовую консоль во вкладку-терминал приложения.
Протокол — [spec/protocol.md](../../spec/protocol.md) §15 и §16; примеры —
[examples/import-csv](../../examples/import-csv) и [examples/console-echo](../../examples/console-echo).

## Импорт

```json
"contributes": {
  "import": [{
    "id": "csv",
    "title": { "ru": "Таблица серверов (CSV)", "en": "Server table (CSV)" },
    "fileExtensions": ["csv", "tsv"],
    "maxSizeMB": 2
  }]
}
```

Пользователь выбирает файл (Файл → Импорт → «Таблица серверов (CSV)…»). Приложение читает его само — до 8 МБ или до
вашего `maxSizeMB` — и передаёт программе **содержимое**; путь к файлу программа не получает. Ответ — папки и
подключения:

```ts
import { defineModule } from "./lib/sshkipper-sdk/index.ts";

defineModule({
  handlers: {},
  importers: {
    csv: (file, ctx) => ({
      nodes: [
        { type: "folder", name: "Production", children: [
          { type: "connection", id: "j", name: "jump", host: "bastion.example.net", port: 2222, user: "ops" },
          { type: "connection", name: "web-1", host: "10.0.1.11", user: "deploy", bastion: "j", tags: ["prod"] },
        ] },
      ],
      warnings: ["строка 7: нет адреса — пропущена"],
    }),
  },
});
```

- `file` — `{ importer, name, size, data: Uint8Array, text() }`. Файл не читается — бросьте `ModuleError`: текст
  увидит пользователь.
- **Пароли и ключи — отдельно.** Если формат их хранит, верните учётные данные (только логин) и секрет отдельным
  списком — приложение спросит пользователя, прежде чем сохранить хоть один:

  ```ts
  credentials: [{ id: "c1", name: "deploy @ web-1", user: "deploy" }],
  secrets: [{ credential: "c1", kind: "password", value: "…" }],
  // а у подключения: credential: "c1"
  ```
- `bastion` — другое подключение ответа (его `id`, иначе имя) или подключение документа пользователя по имени.
- Приложение проверяет ответ до любых изменений: адрес или логин с пробелом или с «-» в начале, порт вне 1…65535,
  неизвестный `credential` — импорт останавливается с указанием места («nodes[2].port — …»). Пределы: 5 000 узлов,
  12 уровней.
- Дальше — как у встроенного импорта ~/.ssh/config: тот же вопрос, слияние и отмена. Повторный импорт обновлённого
  файла обновляет те же узлы (по папке и имени) и не трогает поля, которые пользователь поменял.

Проверять разбор удобно без приложения: пример держит его в `csv.ts`, отдельно от `module.ts`.

## Консоль

```json
"contributes": {
  "console": [{ "id": "sol", "title": "IPMI SoL", "appliesTo": ["connection"] }]
}
```

В меню сервера появляется «Консоль: IPMI SoL». Приложение открывает вкладку с настоящим терминалом (поиск,
копирование, журнал сессии) и вызывает консоль программы с сессией:

```ts
defineModule({
  handlers: {},
  consoles: {
    sol: (session, ctx) => {
      session.write(`Подключено к ${session.node.name}\r\n`);
      session.onInput((bytes) => device.write(bytes));      // что набрал пользователь
      session.onResize((cols, rows) => device.resize(cols, rows));
      session.onClose(() => device.end());                   // вкладку закрыли
      device.on("data", (b) => session.write(b));
      device.on("end", () => session.close("устройство отключилось"));
    },
  },
});
```

- Байты — как есть: пишите то, что шлёт устройство (с ANSI-цветами), перевод строки — `\r\n`. Терминал шлёт то, что
  означает клавиша (Return — `\r`, стрелки — escape-последовательности). У серийной линии нет локального эха: эхо —
  дело устройства.
- `session.node` — `{ id, name, host, port, user }`, без паролей; свой секрет — `ctx.host.secret(key)` (право
  `secrets`). Пока консоль открыта, `ctx.host.exec` может выполнять команды на этом сервере (право `exec`).
- Консоль своего типа узла (`appliesTo: ["<тип>"]`) получает узел так же, как его экран: в `session.node` и `ctx.node` —
  `type`, `settings`, `links` и ключи заданных секретов, `host`/`port`/`user` — сервер, на который указывает поле
  `node`; `ctx.host.nodeSecret(key)` читает секретные поля узла, `ctx.host.exec` выполняет команды на этом сервере.
- Вывод ограничен: всплеск до 4 МБ, дальше 2 МБ в секунду; лишнее отбрасывается, и терминал об этом пишет.
- `session.close(причина)` закрывает консоль со стороны программы; вкладка показывает причину и «Открыть снова».
  Программа завершилась — все её консоли закрываются так же.
- Графическая консоль (KVM, VNC) консолью расширения быть не может: своих пикселей расширение не рисует.

[examples/console-echo](../../examples/console-echo) — учебное серийное устройство: загрузка, эхо, редактирование
строки, цвета, `size`, `flood N` (проверка лимита); ни оболочки, ни порта, ни сети за ним нет.
